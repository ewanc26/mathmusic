    Keyboard and mouse

    Space
    Play / pause
    Home or Enter
    Back to start (or loop start)
    L
    Loop on / off. Drag on the ruler to set the loop.
    ⌘Z, ⇧⌘Z
    Undo, redo
    ⌘S
    Save
    ⌘C, ⌘V, ⌘D
    Copy, paste, duplicate the selected clip
    ⌘E
    Split the selected clip at the playhead
    ⌫
    Delete the selected clip
    T
    Add a track
    M, S
    Mute, solo the selected track
    +, −, F
    Zoom in, out, fit
    1 – 7
    Clip, Track, Effects, Automation, Mixer, Master, Publish
    Double-click lane
    New clip (below the last track: new track)
    Drag clip
    Move, also to another track. Drag its right edge to resize.
    ⌘/Ctrl + scroll
    Zoom the timeline. Shift + scroll pans.

    Every formula uses x. In a clip x runs across the curve; in automation x is the beat; in a waveform x is the phase (one cycle from 0 to 1); in an envelope x runs over the note; in a shaper x is the sample value.
